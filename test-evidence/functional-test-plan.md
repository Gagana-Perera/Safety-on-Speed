# Functional Test Plan — Emergency Services (Extra Tab)

This test plan maps required Emergency Services features to their verification results.

> Note: The current implementation opens the in-app Map tab using a `placeId` (via `expo-router`). It does **not** open the system Maps app with coordinates. If the report strictly requires system Maps coordinates, the app code must be changed to fetch coordinates and open `Linking.openURL()` with a maps URL.
